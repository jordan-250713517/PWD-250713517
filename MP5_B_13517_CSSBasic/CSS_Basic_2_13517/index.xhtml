BEASISWA UAJY

UAJY Menyelengggarakan berbagai program beasiswa dengan kriteria dan manfaat yang berbeda-beda.

  • Beasiswa Program sarjana (s1), yaitu program seleksi siswa berprestasi (PSBB), Beasiswa program internasional (BPI), beasiswa program Akademik (BPA), dan lain-lain.
  • Beasiswa Program Sarjana (s1), yaitu program seleksi siswa berprestasi (PSBB), Beasiswa program internasional (BPI), Beasiswa program Akademik (BPA), dan lain-lain.
  • Beasiswa Program Pascasarjana (s2), yaitu Beasiswa Prestasi Magister (BPM), Beasiswa Magister Unggul (BMU), dan Bima.
